## 🎯 نظرة عامة

تطبيق ويب متكامل يمكّن مديري المدارس من بناء جداول دراسية احترافية في دقائق، مع احترام كل الشروط التربوية والقيود التشغيلية.

**لا يحتاج خادم ولا قاعدة بيانات** — كل شيء يعمل في المتصفح، والبيانات محفوظة محلياً على جهازك.

---

## ✨ الميزات الرئيسية

### 🏫 إدارة المدرسة
- حساب خاص لكل مدرسة (multi-tenant)
- بيانات المدرسة، المدير، المرحلة، العام الدراسي
- رفع شعار المدرسة وتوقيع المدير

### 📚 البيانات الأساسية
- إدارة المواد الدراسية (مع حصص افتراضية وألوان)
- إدارة المدرسين (مع تخصصات وحدود يومية/أسبوعية)
- إدارة الصفوف والشعب
- إسناد ذكي (يدوي + تلقائي مع load balancing)

### 🚦 الشروط والقيود
- الحد الأقصى للحصص المتتالية للمدرّس
- الحد الأقصى للحصص اليومية للصف
- عدد الأيام بين تكرار المادة
- **قيود التوفّر الخاصة** لكل مدرّس (مثلاً: غير متاح الاثنين صباحاً)

### 🎯 التحقق الصارم قبل البناء
قبل توليد الجدول، يفحص النظام:
- ✅ اكتمال كل البيانات
- ✅ سعة كل صف (المطلوب ≤ المتاح)
- ✅ حمل كل مدرّس (أسبوعي + يومي)
- ✅ إمكانية التوزيع الفعلي حسب القيود
- ✅ وجود مدرّس مؤهّل لكل مادة

### 📅 المولّد الذكي
- خوارزمية Greedy + Backtracking
- يوزّع الحصص عبر الأيام بشكل عادل
- يحترم كل القيود
- يشير بوضوح للحصص التي لم تُعيَّن

### 📤 التصدير والطباعة
- **PDF احترافي** (بترويسة رسمية + توقيعات + حقوق الشركة)
- **Excel منسق** (بألوان الرؤوس والصفوف)
- **صورة PNG** عالية الجودة
- **طباعة مباشرة** من المتصفح

### 🗂 ثلاث طرق لعرض الجداول
1. **جداول الصفوف** — جدول منفصل لكل صف/شعبة
2. **جداول المدرسين** — بطاقة لكل مدرّس تعرض كل حصصه
3. **الجدول العام** — كل الصفوف جنباً إلى جنب

## 🚀 الاستخدام السريع

1. افتح الموقع: [رابط GitHub Pages]
2. اضغط **"حساب جديد"** وأنشئ حساب مدرستك
3. اتبع الخطوات 1-8 بالترتيب
4. اضغط **"🚀 تحقق وبناء"**
5. صدّر النتائج (PDF/Excel/PNG)

## 📱 التثبيت كتطبيق (PWA)

الموقع يدعم **Progressive Web App**:

### على الجوال (Android/iOS):
1. افتح الموقع في Chrome/Safari
2. اضغط على **"إضافة للشاشة الرئيسية"**
3. الآن يعمل كتطبيق مستقل — بدون متصفح، وبدون إنترنت

### على الحاسوب (Chrome/Edge):
1. افتح الموقع
2. ابحث عن أيقونة ⬇ في شريط العناوين
3. اضغط **"تثبيت"**

## 🔐 الخصوصية والأمان

- **لا خادم** — كل البيانات في متصفحك (`localStorage`)
- **لا تتبّع** — لا نرسل أي بيانات خارج جهازك
- **كلمات المرور مشفّرة** بـ hash قبل الحفظ
- **عزل تام** — كل مدرسة لا ترى بيانات غيرها

### 💾 النسخ الاحتياطي
- استخدم زر **"تصدير نسخة احتياطية"** (ملف JSON)
- احفظه في مكان آمن (Google Drive، USB، ...)
- لاستعادته على جهاز آخر: **"استعادة نسخة"**
